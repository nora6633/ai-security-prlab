# IT Helpdesk FAQ

**How do I reset my workstation password?**
Use the self-service portal, or contact it-helpdesk@lab.local during support hours.

**Who can access the reporting database?**
Only the data team. Access requests go through the helpdesk and need manager approval.

**Where is the application configured?**
Runtime settings live in `app-config.json`. Ask the operations team before changing them.
